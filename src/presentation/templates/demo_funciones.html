Fundamentos en Tecnologías de Construcción de Software

• Funciones Stateless (Sin Estado / Puras): No dependen ni mutan ningún estado fuera de su alcance. Dado un mismo input, siempre devuelven exactamente el mismo output determinista sin efectos secundarios.
• Funciones Stateful (Con Estado): Modifican o dependen de un estado interno persistido (en memoria del servicio o en la sesión HTTP). Sus resultados cambian en cada invocación sucesiva reflejando el historial acumulado.

Stateless 1 • Función Pura

normalize_product_name_stateless()

Normaliza y sanitiza nombres de medicamentos eliminando tildes (NFKD), caracteres especiales y normalizando espacios de forma determinista.

def normalize_product_name_stateless(raw_name: str) -> str: text = unicodedata.normalize("NFKD", str(raw_name)) text = "".join(c for c in text if not unicodedata.combining(c)) return re.sub(r"[^a-z0-9%.,/\-]+", " ", text.lower()).strip()
Prueba de ejecución en vivo:
Input: " PARACETAMOL 500 mg (Caja x 100 Tab.) / Genérico "
Output: "paracetamol 500 mg caja x 100 tab. / generico"
✓ Idempotencia: Invocada 100 veces con la misma entrada produce exactamente el mismo resultado sin tocar variables de sesión ni memoria.
Stateless 2 • Función Pura

calculate_unit_cost_stateless()

Calcula matemáticamente el costo por unidad (Importe Total / Unidades Totales) protegiendo contra divisiones por cero sin alterar ningún estado.

def calculate_unit_cost_stateless(importe_total, unidades_totales): if unidades_totales <= 0 or importe_total < 0: return None return round(float(importe_total) / float(unidades_totales), 4)
Pruebas de ejecución en vivo:
• calc(150.0, 10.0)  ➔  S/ 15.0000 (Cálculo directo)
• calc(100.0, 3.0)   ➔  S/ 33.3333 (Precisión decimal)
• calc(100.0, 0.0)   ➔  None (Control seguro división entre cero)
✓ Función transparente referencialmente (sin efectos colaterales).
Stateful 1 • Memoria de Servicio

track_invoice_view_stateful()

Registra y acumula el contador de visualizaciones de cada factura en el diccionario interno self._view_counter del servicio.

def track_invoice_view_stateful(self, invoice_id: int) -> int: current_count = self._view_counter.get(invoice_id, 0) + 1 self._view_counter[invoice_id] = current_count return current_count

Stateful 2 • Sesión HTTP

add_search_history_stateful()

Modifica cronológicamente el historial de consultas del usuario almacenado en la sesión HTTP (session['search_history']).

def add_search_history_stateful(session_store, query, max_items=5): history = session_store.get("search_history", []) if query in history: history.remove(query) history.insert(0, query) session_store["search_history"] = history[:max_items] return session_store["search_history"]
Historial en la Sesión del Usuario:
{% if search_history %} {% for q in search_history %} 🕒 {{ q }} {% endfor %} {% else %} Sin búsquedas recientes registradas aún. {% endif %}
Estado de sesión: Almacena secuencialmente las consultas entre diferentes peticiones HTTP.
